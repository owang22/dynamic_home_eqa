The robot is asked where something is, then looks in up to three rooms before answering. Everything it knows comes from those searches; there is no nightly patrol. Days 14 to 23 are shaded: one person is ill and at home, so their things move. Click any point on the plot to read that day.

Read this first: eight comparisons, each answering one question

Every other card on this page is a tool you have to set up. These eight are already set up: two to four lines each, chosen so that everything except the one thing being compared is held still. They follow the measure and the objects boxes at the top and nothing else. Under each plot is the difference between the lines in the windows that matter, worked out from the same questions the plot draws, with a plain yes or no on whether it counts.

Watch the number of homes in each cell. A window needs at least eight questions in a home before it is read at all, and with the objects box set to the ones the illness moves, a single day such as day 14 or day 24 holds only about eight of them — so some homes drop out and the row says three or four homes rather than five. That is the guard working, not a fault. For the single days, set the objects box to all objects, where every home has enough.

Every pair of arms, window by window

The difference between each pair, paired inside each home

One difference per home, then the average and two standard errors across homes. A difference counts only if it clears BOTH two standard errors AND the rerun noise floor — what the same arm, rerun unchanged, moves by on its own. It must also point the same way in every home; a pair that disagrees across homes says so, however large the average. The homes are always taken together here, whatever the home box above is set to, because a paired difference needs more than one home to exist.

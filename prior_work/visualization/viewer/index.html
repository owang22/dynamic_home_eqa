timeline strip (above the slider)

  • blue tick, upper row — the selected object changes receptacle (every move it makes). ◀/▶ jump between these when the dropdown says object moves.
  • red tick, upper row — a left-behind departure: the resident went out on a trip this object usually joins, but it was not taken this time (the "why it moved" box explains it).
  • green tick, lower row — the selected resident starts a new activity. Read the two rows against each other: a blue tick beside a green one is a move caused by that activity; a blue tick with nothing under it drifted while they were out.
  • thin grey line — midnight, one per day.
  • tan line — a weekend midnight (Sat / Sun boundaries), so weekly rhythm is visible at a glance.
  • slider — the current sim time, in 5-minute steps; the clock top-left reads it out. space play/pause, ←/→ jump events.

map

  • gold disc — the selected object, resting on a surface (table, counter, shelf).
  • gold square — the object is on the floor.
  • gold triangle — the object is on a hook.
  • green ring around it — the object is being carried; it sits at the resident's position.
  • grey disc at the dashed AWAY circle — the object left the house (in a bag, at work, in the car).
  • green diamond — a resident; the selected one is drawn larger and opaque, others half-faded; the label reads R1·activity.
  • green-edged tag beside the selected resident — carried items: what they have on them right now, one ringed disc per object plus its name.
  • blue polyline — object path: every receptacle the object has visited so far, in order.
  • green dashed line — resident path: the selected resident's route so far.
  • faint gold discs — trace build-up: where the object has spent its time; radius ∝ √(minutes dwelt), so its usual spots grow.
  • grey cross — a receptacle anchor (a surface or floor spot objects can be placed on); room polygons are tinted per room and labelled with their symbolic id + real region name.

# To the patrol AUT: L515 depth is in millimetres. My 0.84 m was wrong (I applied the camera scale twice)

You're right. The bridge receiver (`l515_go2_pi4_bridge/.../receiver.py`, lines 142-144) converts the camera's native
units (0.00025 m/unit) to metres, then publishes millimetres as 16UC1. So the PNG in each shot is **millimetres**, as
`depth_units` says. I multiplied those mm values by 0.00025 again; that's where 0.84 m came from. Sorry for the noise.

Your 1730 likely comes from a different patch or a different way of handling zeros. The centre is sparse, which
points to a far surface straight ahead. That is consistent with lidar `front_clear_m` 1.06 m, because the lidar
figure is the nearest cell anywhere within ±40°, not the centre.

Advice for using it: ignore zeros, use a robust percentile (e.g. p10 for "how close is anything" in a patch), and
report the valid fraction. Below ~20% valid, treat the patch as unknown.

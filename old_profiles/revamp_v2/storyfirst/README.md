# Synthetic household dataset

Ten simulated households, each observed for 21 continuous days: who lives
there, what they own, everything they do, and every time an object moves.

Generated by `src/revamp_v2/generate_dataset.py`; consolidated into a
single file by `src/revamp_v2/export_dataset.py`.

## The dataset file

    data/household_dataset.jsonl        3.6 MB, one JSON object per line

| field | |
|---|---|
| `household_id` | `hh_001` … `hh_010` |
| `household_type` | e.g. `family_teen_and_child` |
| `days`, `seed` | length of the run, realization seed |
| `residents` | `id`, `name`, `age`, `occupation`, `personality` |
| `receptacles` | `id`, `room` — the furniture objects rest on |
| `objects` | `id`, `class`, `owner`, `home` |
| `activities` | `resident`, `activity`, `at`, `t0`, `t1` |
| `events` | `t`, `object`, `from`, `to`, `by` |

Times are integer minutes from the start of day 0. `at`, `from` and `to`
name a receptacle id, or `ELSEWHERE` when someone is out of the house.
`by` names the activity that caused a movement.

```python
import json
households = [json.loads(l) for l in open("data/household_dataset.jsonl")]
hh = households[3]
{r["id"]: r["name"] for r in hh["residents"]}
# {'resident_1': 'Nadia Flores', 'resident_2': 'Evan Flores', ...}
```

## Per-household files

Each `hh<N>/` directory holds the intermediate artifacts:

    persona.yaml           residents and object inventory
    story.yaml             every resident's 21 days
    object_movement.yaml   per object: home, drift rate, after-rules
    program.yaml           the realization input
    build_log.json         seeds, prompt versions, token usage per call
    timeline_seed0/        events.jsonl, residents.jsonl, hourly.csv,
                           meta.json, trace.json (for the viewer)

## Quality

`realism_panel.md` compares every household against `casas_aruba`, a real
human activity recording. Both acceptance gates pass: burstiness (Fano)
within [1, 6] for 8/10 households, hour-entropy at or above 0.75 for
9/10, and no household has a day without events.

## Reproducing

Responses are cached by seed, so rebuilding replays the original
generation exactly and costs nothing:

    python src/revamp_v2/generate_dataset.py --all --model gpt-5.6-terra
    python src/revamp_v2/export_dataset.py \
        --set profiles/revamp_v2/storyfirst/gpt-5.6-terra \
        --out data/household_dataset.jsonl

Building from scratch (`--force`, or an empty cache) costs about $6.50
and takes roughly half an hour.

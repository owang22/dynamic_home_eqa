# revamp_v1 households — Claude Fable 5

Created **August 7, 2026**.

Narrative household profiles for the revamped simulation set, generated by
**Claude Fable 5** (`claude-fable-5`) in an interactive Claude Code session.
Same 10-household spec and verbatim prompt as the sibling
`chatgpt-5.6sol-high/` set — see `../generation_prompt.md` and
`control.yaml` for the household list and generation status.

Stage 1 only: WHO lives in each home and WHAT objects they own. No clock
times or hour-by-hour routines; the schedule layer comes in a later step.

Status: all 10 households GENERATED (`households/hh_001`–`hh_010`).

Formatting follows the shared canonical style documented in `../README.md`
and enforced by `../normalize_profiles.py`; re-run that script after editing
any profile by hand. Normalization also repaired three words this set had
split across a hand-wrapped line, which YAML folds into a stray `"- "`
inside the string (`longest- running`, `dining- table`, `half- annotated`).
